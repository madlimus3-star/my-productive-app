# สรุปมือถือ (Life Tracker) 📱

เว็บแอปสำหรับมือถือ บันทึกข้อมูลชีวิตประจำวัน ทั้งหมดเก็บในเครื่องผู้ใช้ (localStorage) ไม่ต้องติดตั้งหรือมีเซิร์ฟเวอร์

## ฟีเจอร์
| แท็บ | ฟีเจอร์ |
|------|---------|
| 📊 สรุป | ภาพรวมรายรับ/รายจ่ายเดือนนี้, จำนวน To-Do ค้าง, สถิติตัวนับ |
| 💰 เงิน | บันทึกรายรับ-รายจ่าย พร้อมวันที่และบันทึกย่อ คำนวณยอดคงเหลืออัตโนมัติ |
| ✅ To-Do | เพิ่มสิ่งที่ต้องทำ ติ๊กว่าทำเสร็จแล้ว ลบรายการ |
| 🗂️ บันทึก | บันทึกงาน/โน้ต พร้อมหัวข้อและรายละเอียด |
| 🔢 ตัวนับ | สร้างตัวนับกิจกรรมได้เอง เช่น ออกกำลังกาย, ดื่มน้ำ กด ＋ / − / รีเซ็ต |

## โครงสร้างโปรเจกต์
```
life-tracker-app/
├── index.html      # หน้าจอหลัก
├── css/style.css   # ธีมมือถือ (bottom nav, card)
├── js/app.js       # Logic + localStorage
└── README.md
```

## วิธีใช้งาน
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์เพื่อทดสอบบนมือถือจริง:

```bash
cd life-tracker-app
python3 -m http.server 8080
# เปิด http://localhost:8080 บนคอม หรือเปิดจากมือถือในเครือข่ายเดียวกัน
# ผ่าน http://<IPของคอม>:8080
```

## หมายเหตุ
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ — ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย
- รองรับหน้าจอมือถือเป็นหลัก (mobile-first) ใช้บนคอมได้เช่นกัน
